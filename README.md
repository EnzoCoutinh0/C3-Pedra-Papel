# Pedra, Papel e Tesoura

Jogo de pedra, papel e tesoura contra o computador, feito em JavaScript puro (sem bibliotecas), HTML e CSS.

**Jogo publicado:** https://enzocoutinh0.github.io/C3-Pedra-Papel/

## Como jogar

- Escolha pedra, papel ou tesoura clicando num botão ou usando as teclas `1`, `2` e `3`.
- O computador escolhe ao mesmo tempo, de forma aleatória.
- Pedra quebra tesoura, tesoura corta papel e papel embrulha pedra. Empate não vale ponto.
- Quem fizer 3 pontos primeiro vence a partida.
- No fim, clique em "Jogar de novo" ou aperte `Enter` para recomeçar sem recarregar a página.
- O histórico mostra todas as rodadas da partida.
